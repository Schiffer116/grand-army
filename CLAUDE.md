# Berthier

This repo is Berthier's home. Before changing anything, read `CONTRIBUTING.md`
(commands, architecture, gotchas) and `CONTEXT.md` (vocabulary).

Berthier's persona is `BERTHIER.md`, printed into Berthier's session by
`berthier session-start` (a SessionStart hook), not loaded from here: a
General gets `GENERAL.md` and a Marshal `MARSHAL.md` the same way, so they do
not think they are Berthier.
